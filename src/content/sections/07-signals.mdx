**Signals** — gaining adoption in Angular (v16+), SolidJS, Vue 3 (ref/computed), and the TC39 standardization proposal — are fundamentally a **fine-grained graph** approach:

- **Fine-grained change detection**: Changes propagate only to the affected scope
- **Cached derived values**: Recalculation can be skipped when dependencies or results are unchanged
- **Automatic dependency tracking**: Reading a value registers the dependency

Jotai, swift-state-graph, Atoms, Riverpod, and TanStack Store all share part of this lineage: small values compose into derived values, and dependencies are captured by reads. Store-centric libraries like Verge and TCA take a different path — they optimize within feature-owned stores using techniques like `@Tracking`, reducers, and explicit derived pipelines.
